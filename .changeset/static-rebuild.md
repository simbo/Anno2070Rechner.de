Rebuild the site as a static frontend without server-side code. It looks and
behaves like the old PHP version, with these deliberate changes: login and
registration are gone, umlauts in game data names are shown correctly, pages
change without reloading while all old URLs keep working, calculator inputs are
saved in the browser, and preview tags work for all link previews. It also fixes
the target TPM for a number of buildings with productivity, keeps the settings
of commodity chains in the population calculator and syncs them with the
production buildings, adds a choice of background images with one that changes
daily, fills large windows with a blurred copy of the background, and fixes
small errors of the old site, such as a misspelled page title. The license
changes from GPL 3 to MIT.
